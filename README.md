# Pokedex CLI

A command-line Pokedex tool built with TypeScript. It allows users to interact with the PokeAPI to explore locations, catch Pokemon, and manage a personal Pokedex directly from the terminal.

## Features

- **REPL Interface**: Interactive command-line loop.
- **Explore**: List Pokemon found in different map areas.
- **Catch**: Attempt to catch Pokemon and add them to your Pokedex.
- **Inspect**: View detailed stats of caught Pokemon.
- **Caching**: Local caching of API responses to improve performance and reduce network requests.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Build the project:
   ```bash
   npm run build
   ```

3. Start the CLI:
   ```bash
   npm run dev
   ```
